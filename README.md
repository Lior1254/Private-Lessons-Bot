# Facebook Auto Poster – ליאור שם טוב

פרויקט Python שמעלה פוסטים אוטומטית לקבוצות פייסבוק – עם תמונה, כותרת וטקסט – לפי לוח זמנים קבוע, ללא התערבות ידנית.

---

## מה הפרויקט עושה

הבוט מתחבר לפייסבוק דרך Chrome (Selenium), נכנס לכל קבוצה ברשימה, ומעלה פוסט שמכיל:

- **כותרת קבועה** – למשל `📚 שיעורים פרטיים – ליאור שם טוב`
- **טקסט רנדומלי** – נבחר אוטומטית מתיקיית `posts/texts/`
- **תמונה** – נלקחת מתיקיית `posts/images/`

### מגבלות שיבנו בקוד
| מגבלה | ערך |
|---|---|
| שעות פעילות | 08:00 עד 23:00 בלבד |
| שבת | לא מעלה (מסתיים בשישי ב-18:30, מתחדש במוצאי שבת ב-19:40) |
| תדירות | פוסט אחד ביום, בשעה מתחלפת מתוך `schedule.times` (16:30 / 20:30) |
| בין קבוצות | המתנה אקראית של 3-8 דקות, וכל קבוצה מקבלת טקסט אחר |
| הגנה מספאם | לא מפרסם שוב באותה קבוצה לפני 20 שעות (`logs/last_posted.json`) |

```
📦 שיעורים פרטיים/
├── README.md

```

## config.json

```json
{
  "test_mode": false,         // true = רץ תמיד, false = רק בשעות ולא בשבת
  "schedule": { "times": ["16:30", "20:30"], "min_minutes_between_groups": 3, "max_minutes_between_groups": 8, "min_hours_between_posts_same_group": 20 },
  "post_title": "📚 שיעורים פרטיים – ליאור שם טוב",
  "groups": [
    { "id": "12345678", "name": "שם הקבוצה" }
  ],
  "post_hours": { "start": 8, "end": 23 },
  "shabbat": { "friday_cutoff": "18:30", "saturday_end": "19:40" }
}
```

כדי להוסיף קבוצה – לוקחים את המספר בסוף ה-URL של הקבוצה.

כדי להשבית קבוצה זמנית – מעבירים אותה לשדה `_groups_disabled`.

## התחברות לפייסבוק

בפעם הראשונה – Chrome יפתח ויבקש להתחבר ידנית.
לאחר ההתחברות, הבוט שומר cookies ב-`fb_cookies.json` ומהפעם הבאה נכנס לבד.

אם פייסבוק ביקש להתחבר שוב – מוחקים את `fb_cookies.json` ומריצים מחדש.

## בעיות ידועות ופתרונות

### 1. הבוט לא שולח פוסט בקבוצות שלא יצרתי

**סיבה:** בקבוצות שהמשתמש לא יצר, פייסבוק מציג כפתור `כאן כותבים…` במקום `יצירת פוסט`. ה-XPaths המקוריים לא כיסו את הכפתור הזה.

**פתרון:** הוספנו `//div[@role='button'][contains(.,'כאן כותבים')]` לרשימת ה-XPaths.

**אבחון:** אם הבוט נכשל, הוא מדפיס:
```
[!] כפתור יצירת פוסט לא נמצא. כפתורים בדף: [...]
```
הרשימה מציגה את כל הכפתורים הזמינים – אפשר לזהות מה הכפתור האמיתי ולהוסיף אותו ל-XPaths בפונקציה `post_to_group()`.

---

### 2. זמן המתנה ארוך לפני פרסום

**סיבה:** הלולאה מנסה 10 XPaths, כל אחד ממתין X שניות לפני כישלון. אם הנכון הוא האחרון – זה לוקח הרבה זמן.

**פתרון:** הקטנו timeout לכל XPath מ-4 שניות ל-1.5 שניות.

---

### 3. הכותרת לא נכתבת בחלק מהקבוצות

**סיבה:** בקבוצות שנפתחות דרך `כאן כותבים`, שדה הכותרת הוא `<div contenteditable>` ולא `<input>`, וה-placeholder שלו הוא `יצירת פוסט...` (לא `הוספת כותרת`).

**פתרון:** הוספנו XPaths עבור div עם `@aria-placeholder='יצירת פוסט...'` ו-`@data-placeholder`.

---

### 4. מבנה שדות בדיאלוג – לפי סוג קבוצה

| סוג קבוצה | כפתור פתיחה | placeholder שדה כותרת |
|---|---|---|
| קבוצה שיצרתי | `יצירת פוסט` | `הוספת כותרת` (input) |
| קבוצה שאני חבר | `כאן כותבים…` | `יצירת פוסט...` (div) |

---

### 5. תמונות – הבוט בוחר אקראי

הבוט בוחר תמונה אקראית מ-`posts/images/`. אם יש יותר מתמונה אחת – הוא יבחר בכל פעם אחרת. כדי לשלוט בתמונה: **השאר רק קובץ אחד בתיקייה**.
