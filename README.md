# Facebook Auto Poster – ליאור שם טוב

בוט Python שמפרסם מודעה לשיעורים פרטיים (מתמטיקה, פיזיקה, מדעי המחשב) בקבוצות פייסבוק.

- פעם ביום (16:30 / 20:30 לסירוגין, לא בשבת) Windows מעיר את המחשב משינה.
- הבוט מפרסם לכל הקבוצות ב-`config.json`, טקסט אחר לכל קבוצה, עם הפסקות אקראיות.
- בודק שכל פוסט באמת עלה (✅ פורסם / ⏳ ממתין לאישור / ⚠️ לא אומת / ❌ נכשל), מנסה שוב מה שנכשל.
- שולח דיווח ל-Discord ומחזיר את המחשב לשינה.
- עובד גם כשהמחשב נעול בסיסמה, ולא מפריע כשעובדים על המחשב.

## התחלה מהירה
| | |
|---|---|
| התקנה על מחשב חדש | צעד אחר צעד ב-[`CLAUDE.md`](CLAUDE.md) |
| בדיקה (רק קבוצות דמו) | `test_live.bat` (רואים את Chrome) / `test_hidden.bat` (מוסתר) |
| הפעלת הריצה האוטומטית | `setup_schedule.bat` |
| ביטול | `remove_schedule.bat` |
| ריצה אמיתית עכשיו | `run_once.bat` |

## טכנולוגיות
Python · Selenium (Chrome) · Windows Task Scheduler · Discord Webhook
